工作台助手 0.3.0：轻量个人桌面助理

- 主窗口收敛为今天、清单、记录、设置四个视图。
- 任务简化为 todolist；原有优先级、标签、项目、子任务、工时等数据保留，界面隐藏。
- 新增工作记录：开始/完成任务自动留存快照，支持按日补充，日报/周报读取记录。
- 捕获箱逐条转任务后原备忘录进入回收站，可整体撤销。
- 下线独立任务对话窗口、每日建议、工作流规划；批量与复杂调整走 AI 对话。
- 保留重复任务、提醒、回收站、确认、撤销、托盘、快捷键和本地优先数据存储。
- MCP 默认关闭，可在设置启用。当前目录为 13 个工具；旧版 32 工具中的已下线工具不再可调用。

下载与使用

下载 WorkHelper-0.3.0-win-x64.zip，完整解压至新文件夹后运行 WorkHelper.exe；不要在 ZIP 内直接运行。现有数据目录仍为 %APPDATA%/work-helper/data；替换程序文件不迁移或删除现有任务字段。

SHA256SUMS.txt 可用于核验 ZIP。Windows x64 便携包，无安装器。未提供 Windows 代码签名。
